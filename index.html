SuCSS

Just HTML, already styled.

SuCSS is a classless CSS framework. Write plain HTML — <header>, <table>, <button> — and liquid-glass surfaces, dark mode and accessibility come with it. No class names, no custom attributes, no build step.

This page is the demo. It carries no class attribute anywhere. Paste the line below into your <head> and your own HTML looks like this. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@ryo9ra/su-css/dist-lib/sucss.min.css">

Su (素) is Japanese for plain, or unadorned.

Features

No class names

Styling comes from the elements themselves. There is no naming convention to agree on and no utility classes to memorise.

Dark mode included

Follows prefers-color-scheme, and data-theme pins it either way.

Accessible by default

WCAG AA/AAA contrast, visible :focus-visible rings, adequate touch targets. It honours prefers-reduced-motion and prefers-reduced-transparency too.

Liquid glass

Surfaces behave like a lens rather than a frosted sheet: the backdrop stays legible through them, colour blooms out of them, and every edge carries a rim of light.

One file, no dependencies

A single stylesheet, 4.7 KB minified and gzipped. No JavaScript, no build step.

Tuned with variables

Every colour, radius and rhythm is a custom property. Change --hue and the whole page moves — try it in the customizer.

Install

For the CDN, paste the line above into your <head>. With a bundler, install it from npm. 

npm install @ryo9ra/su-css
import '@ryo9ra/su-css/sucss.min.css';

Supported browsers are Chrome/Edge 111+, Safari 16.4+ and Firefox 128+. Without backdrop-filter, surfaces fall back to solid fills.

Customizing

Colours, radii, spacing and type are all custom properties. A few lines in :root move the whole page — or open the customizer and drag the controls until it looks right. 

:root {
  --hue: 158;          /* accent colour and background mesh */
  --sat: 70%;
  --radius: 0.5rem;    /* calmer corners */
  --max-width: 72ch;   /* width of the body column */
  --base-size: 1rem;
  --font-sans: "Inter", sans-serif;
}

Pinning a theme

By default the theme follows the operating system. data-theme on <html> pins it — which is all the buttons at the top of this page do. 

<html data-theme="dark">   <!-- always dark -->
<html data-theme="light">  <!-- always light -->
<html>                     <!-- follow the OS (default) -->
