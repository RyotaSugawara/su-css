SuCSS

Just HTML, already styled.

SuCSSはクラスレスのCSSフレームワークです。<header>、<table>、<button> のような素のHTMLを書くだけで、リキッドグラスの見た目とダークモードとアクセシビリティがついてきます。クラス名も、カスタム属性も、ビルドも要りません。

このページ自体が見本です。 class 属性は1つも使っていません。次の1行を <head> に貼れば、同じ見た目になります。 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@ryo9ra/su-css/dist-lib/sucss.min.css">

su（素）は「飾りのない、そのままの」という意味です。

特徴

クラス名を書かない

スタイルは要素そのものから決まります。命名規則も、ユーティリティクラスの暗記も要りません。

ダークモード標準

prefers-color-scheme に追従します。data-theme を付ければ固定もできます。

アクセシブル

WCAG AA/AAA のコントラスト、見える :focus-visible リング、十分なタップ領域。prefers-reduced-motion と prefers-reduced-transparency にも従います。

リキッドグラス

面はすりガラスではなくレンズです。背景が透けたまま色がにじみ、縁にはハイライトが乗ります。

1ファイル・依存ゼロ

CSSが1枚だけ。minify + gzip で 4.7 KB。JavaScriptもビルドステップもありません。

変数で調整

色も角丸も余白もCSSカスタムプロパティです。--hue を1行変えれば全体の色が動きます。

インストール

CDNから読み込むなら、上の1行をそのまま <head> に貼ります。バンドラを使うならnpmから入れられます。 

npm install @ryo9ra/su-css
import '@ryo9ra/su-css/sucss.min.css';

対象ブラウザは Chrome/Edge 111+、Safari 16.4+、Firefox 128+ です。backdrop-filter のないブラウザでは、面が半透明ではなくベタ塗りになります。

要素見本

ここから下も、class を1つも使わない素のHTMLです。ブラウザのソース表示で見比べてみてください。

テキスト

段落は --line-height と --max-width にしたがって組まれます。強調、強調（斜体）、太字、イタリック、下線、取り消し線、インラインコード、Ctrl + C、CSS、x、出力、定義語、下付き、上付き、そして リンク がそのまま揃います。

クラス名の設計に費やす時間は、そのままセマンティクスの設計に回せる。

折りたたみ（details / summary）

開閉する領域も、要素だけで組めます。

ダイアログ

<dialog> と背面のバックドロップにもスタイルが当たっています。

コードとメディア

コードブロックは横スクロールします。<figure> と <figcaption> の組み合わせにも対応しています。 

<article>
  <h2>クラスは要らない</h2>
  <p>要素を書くだけで整います。</p>
</article>

カスタマイズ

色・角丸・余白・フォントはすべてCSSカスタムプロパティです。:root に数行足すだけで全体が変わります。 

:root {
  --hue: 158;          /* アクセントと背景メッシュの色相 */
  --sat: 70%;
  --radius: 0.5rem;    /* 角丸を落ち着かせる */
  --max-width: 72ch;   /* 本文カラムの幅 */
  --base-size: 1rem;
  --font-sans: "Zen Kaku Gothic New", sans-serif;
}

ダークモードを固定する

既定ではOSの設定に追従します。<html> の data-theme を切り替えると固定できます。ページ右上のボタンがやっているのもこれです。 

<html data-theme="dark">   <!-- ダークに固定 -->
<html data-theme="light">  <!-- ライトに固定 -->
<html>                     <!-- OSの設定に追従（既定） -->
