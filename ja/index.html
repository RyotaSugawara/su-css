SuCSS

Just HTML, already styled.

SuCSSはクラスレスのCSSフレームワークです。<header>、<table>、<button> のような素のHTMLを書くだけで、リキッドグラスの見た目とダークモードとアクセシビリティがついてきます。クラス名も、カスタム属性も、ビルドも要りません。

このページ自体が見本です。class 属性は1つも使っていません。下の1行を <head> に貼れば、あなたのHTMLもこう表示されます。

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@ryo9ra/su-css/dist-lib/sucss.min.css">

su（素）は「飾りのない、そのままの」という意味です。

特徴

クラス名を書かない

スタイルは要素そのものから決まります。命名規則を決める必要も、ユーティリティクラスを覚える必要もありません。

ダークモード標準

prefers-color-scheme に追従します。data-theme を付ければどちらかに固定できます。

アクセシブル

WCAG AA/AAA のコントラスト、見える :focus-visible リング、十分なタップ領域。prefers-reduced-motion と prefers-reduced-transparency にも従います。

リキッドグラス

面はすりガラスではなくレンズです。背景が透けたまま色がにじみ、縁には光の線が乗ります。

1ファイル・依存ゼロ

CSSが1枚だけ。minify + gzip で 4.7 KB。JavaScriptもビルドステップもありません。

変数で調整

色も角丸もリズムもCSSカスタムプロパティです。--hue を変えればページ全体が動きます — カスタマイザーで試す。

インストール

CDNから読み込むなら、上の1行をそのまま <head> に貼ります。バンドラを使うならnpmから入れられます。

npm install @ryo9ra/su-css
import '@ryo9ra/su-css/sucss.min.css';

対象ブラウザは Chrome/Edge 111+、Safari 16.4+、Firefox 128+ です。backdrop-filter のないブラウザでは、面が半透明ではなくベタ塗りになります。

要素見本

ここから下も class 属性を1つも使わない素のHTMLです。ページのソースを開いて見比べてみてください。

テキスト

段落は --line-height と --max-width にしたがって組まれます。強調、強調（斜体）、太字、イタリック、下線、取り消し線、インラインコード、Ctrl + C、CSS、x、出力、定義語、下付き、上付き、そして リンク がそのまま揃います。

クラス名の設計に費やしていた時間は、そのままセマンティクスの設計に回せる。

折りたたみ（details / summary）

開閉する領域も要素だけで組めます。

ダイアログ

<dialog> と背面のバックドロップ、どちらにもスタイルが当たっています。

コードとメディア

コードブロックはページを押し広げず、横にスクロールします。<figure> と <figcaption> の組み合わせにも対応しています。

<article>
  <h2>No classes needed</h2>
  <p>Write the element and it is styled.</p>
</article>

カスタマイズ

色・角丸・余白・書体はすべてカスタムプロパティです。:root に数行足せばページ全体が動きます。カスタマイザーでつまみを動かしながら決めることもできます。

:root {
  --hue: 158;          /* accent colour and background mesh */
  --sat: 70%;
  --radius: 0.5rem;    /* calmer corners */
  --max-width: 72ch;   /* width of the body column */
  --base-size: 1rem;
  --font-sans: "Inter", sans-serif;
}

テーマを固定する

既定ではOSの設定に追従します。<html> の data-theme で固定できます。このページ上部のボタンがやっているのもそれだけです。

<html data-theme="dark">   <!-- always dark -->
<html data-theme="light">  <!-- always light -->
<html>                     <!-- follow the OS (default) -->
